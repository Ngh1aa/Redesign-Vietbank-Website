### Usage rule
Blue carries trust/navigation/action. Red and yellow are signature accents only; they must not compete with financial status semantics or create misleading urgency.

## 4. Typography

Current concept uses **Be Vietnam Pro**. Status: `PROPOSED_FOR_DIGITAL`; no public Vietbank font standard was verified.

Rules:
- Vietnamese readability first.
- Sentence case for product/task copy.
- Numeric tables use tabular figures where possible.
- Institutional pages use restrained editorial hierarchy rather than oversized campaign typography.

## 5. Brand behavior

The site should communicate:
1. **Am hiểu** → route by user need and explain conditions before CTA.
2. **Chính trực / Tuân thủ** → distinguish official source, concept UI and unknown integration state.
3. **Hiệu quả** → utilities and top tasks are reachable without navigating organization taxonomy.
4. **An toàn** → sensitive actions hand off to verified Vietbank channels; no OTP/login capture in this repository.

## 6. Visual signature guardrail

Recognition should come from a coherent system, not logo + blue only:
- blue institutional keyline;
- small red/yellow dual-accent derived from the logo;
- numbered ledger/statement hierarchy;
- real Vietbank card imagery only on card-selection surfaces;
- restrained annual-report/editorial rhythm on corporate/IR pages.

Do not use generic glassmorphism, decorative banking dashboards, fake card numbers, fake financial charts or unverified seals/certifications.
